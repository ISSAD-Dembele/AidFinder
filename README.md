# AidFinder

AidFinder est une plateforme web intelligente permettant de rechercher des aides financières et subventions selon le profil utilisateur grâce à un chatbot IA.

## Stack Technique

### Frontend
- React.js
- TailwindCSS
- Axios
- React Router DOM

### Backend
- FastAPI
- PostgreSQL

### IA
- API LLM

## Fonctionnalités
- Authentification
- Chatbot IA
- Recherche d’aides
- Historique
- Export PDF
- Responsive Design
